# 아 마따!

업무를 하나 끝낼 때마다 "빠뜨린 게 없나?" 하고 **같은 것을 또 확인하는 습관**을 줄이기 위한 개인용 체크리스트 앱입니다. 확인한 순간 시각을 기록으로 남기고, 다시 확인할 때마다 횟수를 셉니다.

> **관찰 목표**: 확인한 내용과 근거를 남겼을 때 재확인 횟수가 어떻게 달라지는지 여러 날 기록합니다. 하루치 기록만으로 원인을 단정하지 않습니다.

| [amatta.html](amatta.html) | 앱 본체. HTML, CSS, JS가 한 파일(claude.ai Artifact에 올린 코드) |

## 동작

- 항목을 체크하면 시각이 기록됩니다. 체크된 항목에는 "다시 확인했음" 버튼이 있어 항목별 재확인 횟수를 셉니다.
- 항목마다 세부사항을 직접 여러 줄로 추가하고 체크·수정·삭제·순서 변경할 수 있습니다. 템플릿에도 세부사항이 함께 저장됩니다.
- 세부사항이 남은 채 전체 체크를 누르면 경고하지만, 사용자가 필요하면 그대로 진행할 수 있습니다.
- 체크 뒤에는 100자 이내 확인 근거를 남길 수 있고, 재확인 이유도 직접 적을 수 있습니다.
- "하루 끝"에서 총 체크 수, 총 재확인 횟수, **기록을 남긴 뒤에도 다시 확인한 항목 수**를 한 화면에 보여 줍니다.
- Claude는 기존 기준을 덮어쓰지 않고 빠진 기준 2~4개를 미리 제안합니다. 사용자가 고른 것만 추가됩니다.
- 재확인 순간 Claude가 짧게 개입합니다. 기록된 사실을 말하되 위로나 판단은 하지 않습니다. 횟수를 먼저 저장한 뒤 Claude를 호출합니다.
- 시간 측정은 기본으로 꺼져 있으며 필요할 때만 켭니다. 꺼도 재확인 횟수와 이유는 기록됩니다.
- 템플릿 저장, 빠뜨림 기록, 하루 기록 보관, 채용 공고 목록(마감 임박순) 패널이 있습니다.

## 설계 메모

- **인증**: 앱에 Claude 로그인을 직접 구현하지 않고, claude.ai Artifact 안에서 `sample` 기능으로 Claude를 호출합니다. 로그인은 claude.ai가 처리하고 페이지는 키나 토큰을 다루지 않습니다.
- **저장**: Artifact `db`의 본인 전용 경로에 이벤트를 쌓습니다. 클릭마다 페이지를 재발행하면 열린 화면이 다시 불러와지기 때문입니다.
- **측정의 한계**: 개입이 재확인 행동을 바꿀 수 있어, 하루 검증 결과는 "기록의 효과"와 "개입의 효과"가 섞인 값입니다.

## 사용하려면

`amatta.html`을 일반 브라우저로 열어도 직접 입력, 체크, 확인 근거, 재확인 기록과 이 브라우저 안의 저장은 동작합니다. Claude 제안·개입·분석, Claude 계정 저장과 공고 목록은 claude.ai Artifact 런타임(`window.claude`)이 있을 때만 동작합니다.

## 알려진 한계

- 일반 브라우저에서 직접 세부사항 추가, 미완료 경고, 확인 근거, 자유 입력 이유, 새로고침 보존, 선택형 타이머를 확인했습니다.
- Claude Artifact 전용 AI 호출과 계정 저장은 일반 브라우저 테스트만으로는 끝까지 확인할 수 없습니다.
- 공고 상세가 이미지로만 된 경우 글로 읽지 못합니다.
- 가설은 아직 실제 데이터로 검증되지 않았습니다.
