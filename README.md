# 아 마따!

업무를 하나 끝낼 때마다 "빠뜨린 게 없나?" 하고 **같은 것을 또 확인하는 습관**을 줄이기 위한 개인용 체크리스트 앱입니다. 확인한 순간 시각을 기록으로 남기고, 다시 확인할 때마다 횟수를 셉니다.

> **관찰 목표**: 확인한 내용과 근거를 남겼을 때 재확인 횟수가 어떻게 달라지는지 여러 날 기록합니다. 하루치 숫자는 참고일 뿐 원인을 단정하지 않습니다.

## 하는 일

- 항목을 체크하면 시각이 기록됩니다. "다시 확인했음"은 횟수를 먼저 저장한 뒤 Claude가 기록을 근거로 짧게 말합니다. 재확인 이유 칩을 고를 수 있습니다.
- 항목마다 **세부사항을 직접 쓸 수 있습니다.** 여러 줄을 붙여 넣으면 한 줄이 하나가 됩니다.
- 머리말의 **AI 확인 기준** 버튼 하나로, 세부사항이 없는 항목 전부에 AI가 한 번에 확인 기준을 씁니다. 직접 쓴 것은 건드리지 않습니다.
- **AI 개입 켬/끔**: 끄는 하루를 따로 두어 기록의 효과와 AI의 효과를 나눠 봅니다.
- **하루 끝**: 총 체크 수, 총 재확인 횟수, 기록 후에도 다시 확인한 항목 수와 약한 참고 문구("재확인이 적은/많은 편이었어요")를 보여 줍니다. AI 분석과 요약 복사가 있습니다.
- **기록**: 날짜별 표와 막대 그래프. AI 개입을 켠 날과 끈 날의 평균 비교.
- **간단히 보기 / 전체 보기**: 기본은 간단히 보기입니다. 전체 보기에서만 빠뜨림 기록, 템플릿, 큰 화면, 재확인 시간 타이머, 단축키 안내가 보입니다.
- **사람인 스크랩 공고**: 마감 임박(5일 이내)을 강조하고, 지원 완료 표시와 공고별 제출 체크리스트를 지원합니다.

## 설계 메모

- **인증**: 앱에 Claude 로그인을 직접 구현하지 않고, claude.ai Artifact 안에서 `sample` 기능으로 Claude를 호출합니다. 로그인은 claude.ai가 처리하고 페이지는 키나 토큰을 다루지 않습니다.
- **저장**: Artifact `db`의 본인 전용 경로에 이벤트를 쌓습니다. `db`가 없으면 이 브라우저의 저장소로, 그것도 안 되면 메모리에만 저장합니다.
- **측정의 한계**: 재확인 버튼을 누르는 것은 자기 보고라서 안 누른 재확인은 세지 못하고, 개입이 행동을 바꿀 수 있습니다.

## 사용하려면

`amatta.html`을 일반 브라우저로 열어도 직접 입력, 체크, 재확인 기록과 이 브라우저 안의 저장은 동작합니다. Claude 개입·확인 기준·분석, Claude 계정 저장과 공고 목록은 claude.ai Artifact 런타임(`window.claude`)이 있을 때만 동작합니다.

## 테스트

```bash
python -m http.server 5176
```

`http://localhost:5176/tests/index.html`을 열면 27건이 실행되고 제목이 `PASS 27/27`로 바뀝니다. 실제 claude.ai에서의 AI 호출과 동의 창, 폰 화면은 이 테스트로 확인되지 않습니다.

## 알려진 한계

- 하루 사이클을 실제 업무로 여러 날 써 본 기록은 아직 없습니다. 가설은 실제 데이터로 검증되지 않았습니다.
- 공고 상세가 이미지로만 된 경우 글로 읽지 못합니다.
- 다른 작업에서 계획한 V1.1 기능 중 일부(확인 근거, 전체 체크 경고, AI 제안 미리보기 등)는 현재 코드에 없습니다. 기획서 12.3절에 정리했습니다.
