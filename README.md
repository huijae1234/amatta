# 아 마따!

업무를 하나 끝낼 때마다 "빠뜨린 게 없나?" 하고 **같은 것을 또 확인하는 습관**을 줄이기 위한 개인용 체크리스트 앱입니다. 확인한 순간 시각을 기록으로 남기고, 다시 확인할 때마다 횟수를 셉니다.

> **가설**: 확인 즉시 증거를 남기면, 같은 것을 다시 확인하는 횟수가 줄어든다.
> **반증 조건**: 기록을 남겼는데도 기록을 믿지 못하고 또 확인한다면 원인은 기록 부재가 아니라 불안 자체입니다. 앱은 이 경우를 따로 셉니다.

## 파일

| 파일 | 설명 |
|---|---|
| [기획서_아마따_v1.md](기획서_아마따_v1.md) | 문제·가설, 범위, Claude 개입 설계, 인증 결정, 기술 결정 |
| [amatta.html](amatta.html) | 앱 본체. HTML, CSS, JS가 한 파일(claude.ai Artifact에 올린 코드) |

## 동작

- 항목을 체크하면 시각이 기록됩니다. 체크된 항목에는 "다시 확인했음" 버튼이 있어 항목별 재확인 횟수를 셉니다.
- "하루 끝"에서 총 체크 수, 총 재확인 횟수, **기록을 남긴 뒤에도 다시 확인한 항목 수**를 한 화면에 보여 줍니다.
- 재확인 순간 Claude가 짧게 개입합니다. 기록된 사실(체크 시각, 횟수)을 말하고 실제로 확인할 대상을 제안하며, 위로나 판단은 하지 않습니다. 횟수를 먼저 저장한 뒤에 Claude를 호출해서 개입이 측정을 오염시키지 않게 했습니다.
- 템플릿 저장, 빠뜨림 기록, 하루 기록 보관, 채용 공고 목록(마감 임박순) 패널이 있습니다.

## 설계 메모

- **인증**: 앱에 Claude 로그인을 직접 구현하지 않고, claude.ai Artifact 안에서 `sample` 기능으로 Claude를 호출합니다. 로그인은 claude.ai가 처리하고 페이지는 키나 토큰을 다루지 않습니다.
- **저장**: Artifact `db`의 본인 전용 경로에 이벤트를 쌓습니다. 클릭마다 페이지를 재발행하면 열린 화면이 다시 불러와지기 때문입니다.
- **측정의 한계**: 개입이 재확인 행동을 바꿀 수 있어, 하루 검증 결과는 "기록의 효과"와 "개입의 효과"가 섞인 값입니다.

## 사용하려면

`amatta.html`은 claude.ai Artifact 런타임(`window.claude`)을 전제로 합니다. 브라우저로 그냥 열면 화면과 로컬 저장만 동작하고, Claude 개입·계정 저장·공고 목록은 동작하지 않습니다. 쓰려면 claude.ai에서 Artifact로 게시해야 합니다.

## 알려진 한계

- 하루 사이클(체크, 재확인, AI 호출, 하루 끝, AI 분석)을 직접 눌러서 끝까지 검증하지 못했습니다.
- 공고 상세가 이미지로만 된 경우 글로 읽지 못합니다.
- 가설은 아직 실제 데이터로 검증되지 않았습니다.
